# 第 7 阶段（二）：网页改得好读，手机在家里 Wi-Fi 上看（工作树 S11、Q15、W1）

上一篇讲网站怎么自动生成。这一篇讲两件事：网页怎么改得让不懂技术的人也看得懂（S11、Q15），
以及怎么让手机在家里 Wi-Fi 上登录看（W1）。
结论：**网页的数字都能对回预测存档；局域网网站在工作树里测过，但记录写明没有用真手机试过**。
这一篇不涉及模型准不准，模型、融合、门槛、信心规则一个都没改。
代码：`src/web/site/`（网页）、`src/web/serve.py`（局域网服务器）。需求文档第 9、16 节。

## 1. 为什么做

- 你说网页看着费劲，“结论是怎么得出来的”不清楚。网页是给人看的，数字对但看不懂，等于没做。
- 预测网站原来只能在电脑上双击打开。想在手机上看，又不想让外面的网络访问到。

## 2. 网页怎么改（S11、Q15）

### 2.1 一场比赛的页面，从上往下读

以萨索洛对佛罗伦萨为例（记录里逐条核对过这些数）：

1. 最上面一句大字：“佛罗伦萨赢的可能更大（40%）”，下面一根三色条（绿 = 主胜、灰 = 平、蓝 = 客胜，越长越可能）。
2. 6 步“结论是怎么得出来的”，每步写这场自己的数字：
   - 模型算的预期进球：主 1.39、客 1.30；最可能的比分 1–1，概率 12.4%。
   - 16 家博彩公司的赔率去掉抽水后：主 34%、平 26%、客 40%。
   - 合并时赔率占 100%，所以最后的概率就是赔率的概率。
   - 客胜比第二高的多 6.4 个百分点，超过倾向门槛 4 个百分点，所以写倾向。
3. 四块分析：实力对比、近期状态与赛程、伤停与首发、盘口与水位。
4. 模型版本、存档编号这类技术记录收进默认关着的折叠块。

**“去掉抽水”是什么**：博彩公司的三个赔率换成概率加起来会超过 100%（比如 105%），多出来的 5% 是公司的利润。
按比例缩回 100%，才是公司真正认为的概率。

### 2.2 一个要说清楚的地方：w = 1

第 4 阶段定下的融合权重 w = 1，意思是“最后的概率 = 赔率的概率，模型的数只作对照”。
（理由在第 4 阶段那篇：考试里模型没比赔率更准，加进去反而变差。）
Q15 补了一句：w = 1 时，首页“怎么看这张表”写明“这三个数全部来自博彩公司的赔率，模型自己算的在单场页作对照”。
这一点很重要：页面上的概率**不是模型自己的本事**，读者应该知道。

另外首页写了“几乎每场都是 ●●● 高，不等于很有把握”（信心等级为什么几乎全是高，见第 4 阶段信心等级那篇）。

### 2.3 战绩页

先写两行对照：“最新一版猜中几场”和“一直猜主胜能中几场”。
“一直猜主胜”是最笨的办法，模型连它都比不过就说明没用。详细表格收进折叠块。

## 3. 手机怎么看（W1）

### 3.1 做法

电脑上开一个小网站服务器，只把已经生成好的网页发出去，不读数据库、不跑模型、不联网。

| 设计 | 生活版解释 |
|---|---|
| 只在家里 Wi-Fi 里能访问，端口 8790 | 像只在自家院子里开的小卖部，门不朝大街开 |
| 防火墙只在“专用网络”放行，“公用网络”时挡住 | 在咖啡馆、机场的公共 Wi-Fi 上，小卖部自动关门 |
| 要登录，密码随机生成，4 组、每组 4 个字符，约 79 位随机性 | 79 位随机性 ≈ 2 的 79 次方种可能，一个一个猜猜不完 |
| 密码只存“加盐哈希”（PBKDF2） | 存的是密码搅碎后的样子，不是密码本身；“加盐”是每家搅的方法不一样，别人拿一份搅碎表没法通用 |
| 同一设备连续输错 5 次锁 15 分钟 | 防止有人一直试 |
| 登录一次 30 天内不用再登 | |
| 网址里有 `..`、反斜杠这类写法一律 404 | `..` 是“上一层文件夹”，防止有人借网址翻到网站文件夹外面的文件 |
| 同时最多 32 个连接 | 防止被太多请求拖垮 |
| 日志不记密码和登录凭证 | |

账号、密码、网址写在本机 `data/` 下的一个文本文件里，`data/` 不进 Git，所以公开仓库里没有。

### 3.2 风险

网站是 http，不加密。家里 Wi-Fi 上问题不大；密码只防同一个 Wi-Fi 里的其他人。

## 4. 结果

- S11 在真实数据副本上试生成：195 页、91 场有预测、0 条提示。
- W1 在工作树里把正式网站拷过来，在本机地址上起服务器登录看了一遍：首页、战绩页、单场页、球队页、生命周期页、数据状态页正常，
  106 个页面里的链接都能打开（战绩页的周报、月报链接一开始打不开，补上了）。
- 自动检查真的在本机随机端口起服务器测登录、退出、过期、锁定、20 多种路径穿越写法等，测完就关。

## 5. 局限

- W1 工作树里**没有用真手机试过**，没有注册定时任务、没有加防火墙规则，部署由合并后做。部署后有没有用手机实测，记录里没写。
- 伤停与首发：模型不看，页面照实写。首发后来另做了（见第 5 阶段首发那篇）。
- 网页是“改得好读”，不是“改得更准”。

## 6. 常见误区

- **“网页上主胜 34%，是模型算出来的。”** w = 1 时这是赔率的概率，模型的数在单场页作对照。
- **“有密码就安全了，公共 Wi-Fi 也能开。”** http 不加密，同一个网络里的人可能看到传的内容。所以公用网络时直接挡住。

## 7. 小练习

三个赔率换成概率是 50%、30%、25%（数字是编的），去掉抽水后各是多少？

<details><summary>答案</summary>

加起来 105%，多出 5% 是抽水。各除以 1.05：约 47.6%、28.6%、23.8%，加起来 100%。

</details>
