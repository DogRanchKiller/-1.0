# 第 3 阶段（二）：三个检验和市场比分矩阵

有了模型（dc）和标杆（赔率），下一个问题是：**模型和赔率不一样的时候，信谁？**
需求文档第 5 节定了三个检验来回答。这一篇讲三个检验怎么做、结果是什么，以及怎么从赔率反推一张“市场比分矩阵”（以后融合要用）。
代码：`src/evaluate/market_checks.py`；反推程序后来挪到 `src/common/markets.py`。
结论：dc 用的公开比分信息，赛前赔率早就用足了；dc 和赔率不一样时，多半是 dc 错。

## 1. 直觉：三个问题

1. **整体谁更准？** 同一批比赛，比 log loss。
2. **分歧时谁更准？** 只看两边差得多的比赛。也许整体输，但“意见不一样”的时候模型反而对？
3. **赔率会不会往模型那边走？** 从赛前到收盘，赔率会因为新消息变动。如果模型抓到了市场还没用上的信息，
   收盘时赔率应该往模型那边挪。这个检验看的是价格变动，受比赛结果的运气影响小，是判断模型有没有价值最直接的证据。

## 2. 关键公式

**分歧**：模型和赛前赔率在主胜、平、客胜三个概率上差得最多的那个（绝对值）。分三组：3% 以内、3%–6%、6% 以上。

**跟随比例 β**（检验三）。每场：

- d = 模型 − 赛前赔率（三个概率的差，例如 [+0.05, −0.02, −0.03]）
- m = 收盘赔率 − 赛前赔率（同一家公司，三个概率的差）
- d · m 是“点乘”：三个位置对应相乘再相加。

β = 所有比赛 (d · m) 之和 ÷ 所有比赛 (d · d) 之和

| β | 意思 |
|---|---|
| 0 | 赔率怎么变和模型无关 |
| 1 | 收盘时正好走到模型的位置 |
| 0.1 | 平均走了模型和赔率差距的十分之一 |

例（一场，数是编的）：d = [0.05, −0.02, −0.03]，m = [0.01, 0, −0.01]。
d · m = 0.0005 + 0 + 0.0003 = 0.0008；d · d = 0.0025 + 0.0004 + 0.0009 = 0.0038；只看这一场 β = 0.0008 ÷ 0.0038 ≈ 0.21。

**市场比分矩阵**：每场找两队预期进球 λ主、λ客，让泊松比分矩阵算出的“主胜、平、客胜、大 2.5 球”四个概率和去水后的赔率最接近
（差的平方和最小，用高斯-牛顿法解）。两个未知数对四个数，一般凑不齐，凑不齐的部分叫**还原误差**。

## 3. 项目里怎么做的

- 规则在跑之前写进需求文档第 5 节“三个检验和市场比分矩阵怎么做”，设置在 settings.yaml 的 `market_checks`
  （分歧分组 [0.03, 0.06]，最大概率 ≥ 0.60 算“强弱分明”）。
- 模型：dc 的滚动回测 T-24 预测，五大联赛 2005/06–2023/24，34,519 场（回测 t3_dc）。
- 赛前赔率：有平博赛前用平博（2012/13 起），没有用多家平均赛前。按比例去水。
- 收盘只用**同一家公司**的收盘，这样 m 只是这一家自己的变化，不混进两家公司本来的差别。
- 局限：football-data 只有一个赛前时点，T-24 和 T-1 拿到同一组赔率，分开统计现在做不了；回测的比赛都是联赛，杯赛没有赔率。
- 市场比分矩阵用多家平均赛前的胜平负和大小球 2.5，先不加 DC 的 ρ（当时的判断是四个概率定不出三个数；第 4 阶段找到了分两步的办法，见第 4 节最后）。

## 4. 结果和怎么读

34,519 场里 34,517 场有赛前赔率（平博 21,710 场、多家平均 12,807 场），21,716 场有同一家的收盘。

**检验一**：dc log loss 0.9892，赛前赔率 0.9739，dc 差 0.0153（区间 0.0137 到 0.0170）；比收盘差 0.0194。五个联赛都更差。

**检验二**（dc − 赛前赔率的 log loss 差）

| 分歧 | 差 |
|---|---|
| 3% 以内 | +0.0013 |
| 3%–6% | +0.0071 |
| 6% 以上 | +0.0341 |

分歧越大，dc 输得越多；6% 以上时 dc 更准的比赛只占 42%。没有一组是“模型更准”。

**检验三**：β = 0.0005（区间 −0.0065 到 0.0076），几乎是 0。分歧 3% 以上、赔率变了的比赛里，往 dc 方向走的占 48.7%（47.9% 到 49.5%），
和抛硬币一样。

怎么读：三个检验说的是同一件事。dc 只用了公开的比分，赔率早就把这些用足了；dc 多出来的“意见”多半是噪声。
所以融合时 dc 的权重应该很小（后来用 A 版重选，w = 1，见第 4 阶段“融合权重和倾向门槛”）。

**市场比分矩阵**（34,514 场）

- 还原误差（平均 / 99% 的场在多少以内）：主胜 0.009 / 0.025，平 0.020 / 0.046，客胜 0.011 / 0.028，大 2.5 球 0.007 / 0.017。
- 平局系统性少给 2 个百分点：独立泊松给的平局本来就偏少（步骤 1 的老问题）。
- 最大的差（平 0.28、大 2.5 球 0.41）是意甲几场赛季末的比赛：赔率给平局 60% 以上，泊松矩阵拟合不了。
- 和 dc 比：比分 log loss 2.8589 对 2.8873，好 0.028；大 2.5 球、双方进球也更准。还原出的胜平负 log loss 0.9760，
  比 dc 好 0.0131，比去水赔率本身差 0.0018（这就是还原误差的代价）。

后来（第 4 阶段 W9）给市场矩阵加了 ρ（`fit_market_dc`）：ρ 只在 0:0、0:1、1:0、1:1 四格之间挪概率，不改“主胜 − 客胜”和大 2.5 球。
所以分两步：先用两个 λ 对上“主胜 − 客胜”和大 2.5 球，再用 ρ 补平局。这样四个数都能对上。
加了 ρ 以后平均还原误差只剩 0.00003，ρ 的中位数 −0.095（市场比独立泊松多给平局）；
还对不上的 26 场还是意甲 2005/06–2012/13 赛季末那些“平局赔率只有 1.29–1.45”的比赛（需求文档第 5 节“用 A 版重选融合权重和倾向门槛 结果”）。

## 5. 常见误区

1. **整体输了，就说模型一无是处。** 检验一只说“平均谁更准”。检验二、三就是为了找“整体输、某类比赛赢”的情况设的。
   这次三个检验结论一致（dc 没有额外信息），才能下这个结论；只做检验一是不够的。
2. **分歧大 = 机会大。** 直觉上“模型和庄家差 6% 以上，一定有一边错得厉害，说不定是庄家”。实际是 dc 输得最多（+0.0341），
   dc 更准的比赛只占 42%。分歧大多半说明模型在这场看漏了什么（首发、伤停、战意），不是庄家错。
   这个项目不给下注推荐；涉及赔率的只做虚拟投注，用来学习。
3. **检验三混用两家公司。** 赛前用平博、收盘用多家平均，m 里就混进了“两家公司本来就不一样”，β 会被这部分带偏。
   所以只用同一家公司的赛前和收盘。
4. **β > 0 就说模型知道内幕。** 模型只用了 T-24 以前公开的比分。就算 β > 0，也只说明赛前赔率还没把公开信息用足，
   不说明模型知道别人不知道的事（需求文档第 5 节检验三的“注意”）。
5. **分组分得越细越好。** 检验二可以按联赛、强弱、主客继续往下分，组越多，越容易碰巧冒出一组“模型更准”。
   所以事先规定：区间整个在“模型更准”一边才说，而且最后以期末考试为准。
6. **以为市场矩阵“还原”了赔率就没有误差。** 不加 ρ 时还原出的胜平负比去水赔率本身差 0.0018，这就是还原误差的代价。
   融合前要先看还原误差有多大，不然融合出来的变化可能只是还原误差。

## 6. 小练习

**练习 1**：两场比赛（数是编的）。第一场 d = [+0.04, −0.01, −0.03]，m = [+0.02, 0, −0.02]；第二场 d = [−0.05, +0.02, +0.03]，m = [+0.01, 0, −0.01]。
（1）每场的 d · m 是多少？哪一场赔率往模型那边走了？（2）两场合起来 β 是多少？

<details><summary>答案</summary>

（1）第一场：0.04 × 0.02 + 0 + (−0.03) × (−0.02) = 0.0008 + 0.0006 = **+0.0014**，往模型那边走了。
第二场：(−0.05) × 0.01 + 0 + 0.03 × (−0.01) = −0.0005 − 0.0003 = **−0.0008**，往反方向走（模型更不看好主队，收盘反而更看好主队）。

（2）d · d：第一场 0.0016 + 0.0001 + 0.0009 = 0.0026；第二场 0.0025 + 0.0004 + 0.0009 = 0.0038；合计 0.0064。
β = (0.0014 − 0.0008) ÷ 0.0064 = 0.0006 ÷ 0.0064 ≈ **0.094**：平均走了差距的十分之一不到。
真实结果是 β = 0.0005，比这个还小得多。

</details>

**练习 2**：某场模型给 主胜 48%、平 27%、客胜 25%，去水赛前赔率给 主胜 52%、平 26%、客胜 22%。
（1）分歧是多少？属于哪一组？（2）这一组 dc 平均比赔率差多少？

<details><summary>答案</summary>

（1）三个差：−4%、+1%、+3%，绝对值最大的是 **4%**，属于 **3%–6%** 组。
（2）这一组 dc − 赛前赔率的 log loss 差是 **+0.0071**，dc 更差。

</details>

**练习 3**：λ主 = 1.4、λ客 = 1.1，独立泊松矩阵上加 ρ = −0.1。DC 修正后 0:0、1:0、0:1、1:1 四格分别乘
(1 − λ主λ客ρ)、(1 + λ客ρ)、(1 + λ主ρ)、(1 − ρ)。算出来平局多了 0.0253，主胜、客胜各少了 0.0126。
（1）为什么主胜、客胜少得一样多？（2）为什么这一步不改大 2.5 球？

<details><summary>答案</summary>

（1）1:0 那格变了 P(1:0) × λ客ρ = e^(−λ主−λ客) × λ主 × λ客 × ρ；0:1 那格变了 P(0:1) × λ主ρ = e^(−λ主−λ客) × λ客 × λ主 × ρ。两个式子一样，
所以主胜、客胜变得一样多，“主胜 − 客胜”不变；四格加起来变化是 0（概率总和还是 1），平局就多了两倍那么多。

（2）四格都是 0、1、2 个进球，全在“小 2.5 球”那边，格子之间挪来挪去，大 2.5 球的总数不变。
所以两个 λ 定“主胜 − 客胜”和大 2.5 球，ρ 单独定平局，三个数正好对上三个独立的数（胜平负三个概率加起来是 1，只算两个）。

</details>

**练习 4**：有人说：“检验二里分歧 6% 以上时 dc 有 42% 的比赛更准，那这 42% 的比赛按 dc 去买，就能赚钱。”哪里不对？

<details><summary>答案</summary>

事先不知道哪 42% 是 dc 对的。平均下来这一组 dc 输 0.0341，照 dc 买会亏；何况真实赔率还有抽水。
这只是“模型和赔率谁更可信”的证据，不是下注信号。项目只做虚拟投注，用来学习。

</details>

**练习 5**：为什么检验三只用有收盘赔率的比赛，2005/06–2011/12 这几季不算？

<details><summary>答案</summary>

检验三要 m = 收盘 − 赛前，而且是同一家公司。平博收盘 2012/13 起才有，多家平均收盘 2019/20 起才有；
2005/06–2011/12 这几季用的是多家平均赛前，同一家没有收盘，算不出 m。

</details>
