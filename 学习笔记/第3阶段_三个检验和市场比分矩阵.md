# 第 3 阶段（二）：三个检验和市场比分矩阵

有了模型（dc）和标杆（赔率），下一个问题是：**模型和赔率不一样的时候，信谁？**
需求文档第 5 节定了三个检验来回答。这一篇讲三个检验怎么做、结果是什么，以及怎么从赔率反推一张“市场比分矩阵”（以后融合要用）。
代码：`src/evaluate/market_checks.py`；反推程序后来挪到 `src/common/markets.py`。
结论：dc 用的公开比分信息，赛前赔率早就用足了；dc 和赔率不一样时，多半是 dc 错。

## 1. 直觉：三个问题

1. **整体谁更准？** 同一批比赛，比 log loss。
2. **分歧时谁更准？** 只看两边差得多的比赛。也许整体输，但“意见不一样”的时候模型反而对？
3. **赔率会不会往模型那边走？** 从赛前到收盘，赔率会因为新消息变动。如果模型抓到了市场还没用上的信息，
   收盘时赔率应该往模型那边挪。这个检验看的是价格变动，受比赛结果的运气影响小，是判断模型有没有价值最直接的证据。

## 2. 关键公式

**分歧**：模型和赛前赔率在主胜、平、客胜三个概率上差得最多的那个（绝对值）。分三组：3% 以内、3%–6%、6% 以上。

**跟随比例 β**（检验三）。每场：

- d = 模型 − 赛前赔率（三个概率的差，例如 [+0.05, −0.02, −0.03]）
- m = 收盘赔率 − 赛前赔率（同一家公司，三个概率的差）
- d · m 是“点乘”：三个位置对应相乘再相加。

β = 所有比赛 (d · m) 之和 ÷ 所有比赛 (d · d) 之和

| β | 意思 |
|---|---|
| 0 | 赔率怎么变和模型无关 |
| 1 | 收盘时正好走到模型的位置 |
| 0.1 | 平均走了模型和赔率差距的十分之一 |

例（一场，数是编的）：d = [0.05, −0.02, −0.03]，m = [0.01, 0, −0.01]。
d · m = 0.0005 + 0 + 0.0003 = 0.0008；d · d = 0.0025 + 0.0004 + 0.0009 = 0.0038；只看这一场 β = 0.0008 ÷ 0.0038 ≈ 0.21。

**市场比分矩阵**：每场找两队预期进球 λ主、λ客，让泊松比分矩阵算出的“主胜、平、客胜、大 2.5 球”四个概率和去水后的赔率最接近
（差的平方和最小，用高斯-牛顿法解）。两个未知数对四个数，一般凑不齐，凑不齐的部分叫**还原误差**。

## 3. 项目里怎么做的

- 规则在跑之前写进需求文档第 5 节“三个检验和市场比分矩阵怎么做”，设置在 settings.yaml 的 `market_checks`
  （分歧分组 [0.03, 0.06]，最大概率 ≥ 0.60 算“强弱分明”）。
- 模型：dc 的滚动回测 T-24 预测，五大联赛 2005/06–2023/24，34,519 场（回测 t3_dc）。
- 赛前赔率：有平博赛前用平博（2012/13 起），没有用多家平均赛前。按比例去水。
- 收盘只用**同一家公司**的收盘，这样 m 只是这一家自己的变化，不混进两家公司本来的差别。
- 局限：football-data 只有一个赛前时点，T-24 和 T-1 拿到同一组赔率，分开统计现在做不了；回测的比赛都是联赛，杯赛没有赔率。
- 市场比分矩阵用多家平均赛前的胜平负和大小球 2.5，先不加 DC 的 ρ（当时的判断是四个概率定不出三个数；第 4 阶段找到了分两步的办法，见第 4 节最后）。

## 4. 结果和怎么读

34,519 场里 34,517 场有赛前赔率（平博 21,710 场、多家平均 12,807 场），21,716 场有同一家的收盘。

**检验一**：dc log loss 0.9892，赛前赔率 0.9739，dc 差 0.0153（区间 0.0137 到 0.0170）；比收盘差 0.0194。五个联赛都更差。

**检验二**（dc − 赛前赔率的 log loss 差）

| 分歧 | 差 |
|---|---|
| 3% 以内 | +0.0013 |
| 3%–6% | +0.0071 |
| 6% 以上 | +0.0341 |

分歧越大，dc 输得越多；6% 以上时 dc 更准的比赛只占 42%。没有一组是“模型更准”。

**检验三**：β = 0.0005（区间 −0.0065 到 0.0076），几乎是 0。分歧 3% 以上、赔率变了的比赛里，往 dc 方向走的占 48.7%（47.9% 到 49.5%），
和抛硬币一样。

怎么读：三个检验说的是同一件事。dc 只用了公开的比分，赔率早就把这些用足了；dc 多出来的“意见”多半是噪声。
所以融合时 dc 的权重应该很小（后来用 A 版重选，w = 1，见第 4 阶段“融合权重和倾向门槛”）。

**市场比分矩阵**（34,514 场）

- 还原误差（平均 / 99% 的场在多少以内）：主胜 0.009 / 0.025，平 0.020 / 0.046，客胜 0.011 / 0.028，大 2.5 球 0.007 / 0.017。
- 平局系统性少给 2 个百分点：独立泊松给的平局本来就偏少（步骤 1 的老问题）。
- 最大的差（平 0.28、大 2.5 球 0.41）是意甲几场赛季末的比赛：赔率给平局 60% 以上，泊松矩阵拟合不了。
- 和 dc 比：比分 log loss 2.8589 对 2.8873，好 0.028；大 2.5 球、双方进球也更准。还原出的胜平负 log loss 0.9760，
  比 dc 好 0.0131，比去水赔率本身差 0.0018（这就是还原误差的代价）。

后来（第 4 阶段 W9）给市场矩阵加了 ρ（`fit_market_dc`）：ρ 只在 0:0、0:1、1:0、1:1 四格之间挪概率，不改“主胜 − 客胜”和大 2.5 球。
所以分两步：先用两个 λ 对上“主胜 − 客胜”和大 2.5 球，再用 ρ 补平局。这样四个数都能对上。
