# 第 8 阶段：用欧战比较不同联赛的实力（工作树 S8，加合并审查修正）

联赛里每队的实力都是“和本联赛其他队比”，英超的 +0.2 和西甲的 +0.2 不能直接比。欧战是唯一有跨联赛比赛的地方。
这一阶段用欧战比赛给每个联赛估一个“联赛偏移”δ，看加上它以后欧战比赛预测得准不准。
结论：**加 δ 以后欧战胜平负的 log loss 更准**（差 −0.025，区间不跨 0），合并审查修正了一个归属错误后方向不变；
欧战表现和接下来联赛成绩之间只算“有迹象”。**不上线、不改任何模型，也不能说哪个联赛更强。**
代码：`src/features/euro_matches.py`、`src/models/euro_strength.py`、`src/evaluate/euro_study.py`。需求文档第 4 节“第 8 阶段怎么做”“第 8 阶段合并审查修正与复核”。

## 1. 为什么做

想象两所学校各自考试排名。A 校第一名 95 分，B 校第一名也 95 分，但两校卷子难度不一样，分数不能直接比。
要比，得找两校学生做过同一张卷子的场合。足球里，欧冠、欧联、欧协联就是“同一张卷子”。

要回答两个问题：
1. 欧战里能不能估出每个联赛整体差多少（δ），加上以后预测欧战比赛更准吗？
2. 一队欧战里打得比预期好，接下来联赛也会比预期好吗？（只做“残差研究”，只报告）

## 2. 怎么做

### 2.1 联赛偏移 δ

每场欧战的预期进球：主队进攻 + 主队所在联赛的 δ，对上客队防守 + 客队所在联赛的 δ，再加主场优势。
- 五大联赛各一个 δ，“联赛外”所有球队共用一个 δ（它们只和五大联赛球队踢过，估不出个别球队）。
- δ 最后都减去五个联赛的平均，表示“比五大联赛平均高还是低”。
- 对照组：δ 全是 0，等于把各联赛内的分数直接当成同一把尺子。

### 2.2 事先定的规则

- 比分用 90 分钟的，加时和点球不用（模型出的是 90 分钟比分）。
- 决赛、2019/20 疫情后的单场淘汰赛当中立场（库里没有中立场标记，是推断的）。
- 两回合各算一场。第 1 回合、第 2 回合、小组赛、单场分开报告。
- 疑似重复的比赛（同一场因队名写法不同存了两次）合并。预期 7 对，实际找到 7 对，例如 Dortmund – Odds BK 和 Dortmund – Odd。
- T-24 出预测；开发赛季 2005/06 起估计，评 2014/15–2023/24。2024、2025 不碰。
- **判定只看两个数**：主比较（log loss 差）和主残差（90 天窗口的 b）。其余几十个分组数只看方向。

## 3. 合并审查发现的问题

审查时发现：Birmingham（2011/12，8 场）、Wigan（2013/14，6 场）那一季已经降到英冠，程序却沿用上一季名单，把它们算成英超球队。
原来摸底说次级联赛球队“只有 2 场”（Guingamp），实际是 16 场。
修法：每场欧战按**自己那个赛季**的联赛名单认球队。先写 4 个会失败的测试，确认失败，再改程序。误归属的场数从 14 降到 0。
另外原程序把第 1、2 回合合成了一行“两回合”，和事先定的规则不一致，也改成分开报告。

这是个好例子：**错误不一定让结果变难看**。这里修完结论没变，但不修就不知道。

## 4. 结果（修正后）

### 4.1 主比较（2,568 场欧战，差 = 加 δ − 对照，负数 = 更准）

| 尺子 | 对照（δ 全 0） | 加 δ | 差 | 95% 区间 |
|---|---|---|---|---|
| log loss（判定用） | 0.966632 | 0.941546 | −0.025086 | −0.035284 到 −0.014472 |
| Brier | | | −0.018278 | |
| RPS | | | −0.008560 | |

区间整个小于 0，按规则判“更准”。

### 4.2 分开看（只看方向）

| 分组 | 场数 | log loss 差 |
|---|---|---|
| 第 1 回合 | 473 | −0.028158 |
| 第 2 回合 | 470 | −0.007501 |
| 小组赛 | 1,568 | −0.028190 |
| 单场 | 57 | −0.059194 |
| 两队同一组（δ 互相抵消） | 34 | −0.0002 |

修正前的记录里还有：欧冠 −0.0015、欧联 −0.0447、欧协联 −0.0378；10 个赛季里 8 个为负（2017 +0.0022、2021 +0.0047 略差）。
修正后这几项有没有重算，记录里没写。

同组 34 场几乎没差别，这是对的：两队都在同一个联赛，δ 一加一减抵消了。

### 4.3 残差研究

y = 这队联赛里实际净胜球 − 模型预期净胜球；x = 过去 90 天欧战里平均“超预期净胜球”。
结果 b = 0.058183，95% 区间 0.024366 到 0.091551（10,401 行）。
意思是：欧战里平均每多超预期 1 个净胜球，接下来联赛里平均比预期多约 0.06 个。区间不跨 0，但按规则**只算“有迹象”**。

为什么只算有迹象：相关不是因果。欧战打得好的队可能本来就变强了，只是模型还没跟上；休息、疲劳也混在里面。
同一队有很多行、窗口互相重叠，区间可能偏窄。

## 5. 结论

- 加联赛偏移，欧战比赛预测更准。只记下，不上线，`current_stage` 仍是 2。
- 残差研究有迹象，不做模型。要做得另写规则、开发赛季回测、再影子运行（新旧两版同时出，页面用旧版，新版只存档）。
- 这次没有考试赛季可用（2024、2025 已经考过预测部分），以后影子运行是唯一“没看过的数据”。

## 6. 局限和不能下的结论

- **不能说某联赛比某联赛强**。参加欧战的是各联赛的上层球队，不是整个联赛。修正前最后一步的 δ（英超 0.0966、西甲 −0.0217、德甲 0.0217、意甲 −0.0053、法甲 −0.0912、联赛外 −0.1747）只说明欧战球队这个样本。
- 好处可能主要来自“联赛外”那个 δ（−0.17）：对照版把联赛外球队当成平均水平，显然高估了。没做“只放联赛外 δ”的对照，所以不能说五个联赛之间的差别本身有用。
- 每季约 250 场欧战、六个 δ，样本小。
- 不报晋级概率。

## 7. 小练习

两队都来自英超，加 δ 前后预测为什么几乎一样？

<details><summary>答案</summary>

主队进攻加英超 δ，客队防守也加英超 δ，两个一样的数在“进攻 − 防守”里抵消了。所以同组 34 场差只有 −0.0002。

</details>
