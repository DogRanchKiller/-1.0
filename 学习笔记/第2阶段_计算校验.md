# 第 2 阶段（起步）：计算工具和手算校验

第 2 阶段要做回测和模型。在这之前，先把几样“算错了不会报错、只会悄悄让结果变差”的计算写好、核对好：
去水、亚盘和大小球结算、比分矩阵、评分指标。每样都用小例子手算一遍，程序算出来的数必须和手算一样，
这些例子都放进了自动检查（`tests/test_calc.py`、`tests/test_metrics.py`），以后每次改代码都会重新核对。

| 文件 | 做什么 |
|---|---|
| `src/common/odds.py` | 赔率 → 概率，赔率倒数之和，三种去水方法 |
| `src/common/settlement.py` | 亚盘、大小球一场比赛怎么结算，赢了输了各多少钱 |
| `src/common/markets.py` | 比分矩阵 → 胜平负、大小球、亚盘、BTTS、比分的概率 |
| `src/evaluate/metrics.py` | 评分：log loss、Brier、RPS、校准表、ECE |

本文的赔率都是欧洲小数赔率：1.90 表示下 1 元，赢了一共拿回 1.90 元（含本金 1 元，净赚 0.90 元）。

## 1. 赔率、抽水和去水

### 赔率里藏着概率

赔率的倒数叫**隐含概率**：赔率 2.0 → 1 ÷ 2.0 = 50%。意思是：如果这个结果真有 50% 的机会，按 2.0 下注长期不赚不亏。

### 抽水

一场比赛胜平负赔率 2.0 / 3.5 / 4.0：

| | 主胜 | 平 | 客胜 | 合计 |
|---|---|---|---|---|
| 赔率 | 2.0 | 3.5 | 4.0 | |
| 隐含概率 | 50.00% | 28.57% | 25.00% | **103.57%** |

三个结果一定会发生一个，真实概率加起来应该是 100%。多出来的 3.57% 就是庄家的**抽水**：
每个结果的价格都比公平价格低一点，不管谁赢，庄家长期都赚这一点。
“隐含概率加起来”这个数（这里 1.0357）英文叫 overround，程序里叫“赔率倒数之和”。

注意：国内网站说的“水位”（例如 0.85）是另一回事，是香港盘的赔率写法，0.85 = 欧洲赔率 1.85。

### 去水：把抽水拿掉，得到“市场认为的真实概率”

**方法 1：按比例（默认）**。每个隐含概率都除以合计：

- 主胜 50.00 ÷ 103.57 = 48.28%
- 平 28.57 ÷ 103.57 = 27.59%
- 客胜 25.00 ÷ 103.57 = 24.14%
- 加起来正好 100%。

（用分数算更干净：1/2 = 14/28，1/3.5 = 8/28，1/4 = 7/28，合计 29/28，去水后 14/29、8/29、7/29。）

**方法 2：Shin 法**。想法是：市场上有一小部分人知道内幕，他们专买会赢的那一边。冷门一旦被他们买中，庄家要赔很多，
所以庄家给冷门抽得更多。反过来去水时，冷门要多减一点。程序从赔率反推出“内幕玩家的比例” z，这场 z ≈ 1.8%。

**方法 3：幂函数法**。每个隐含概率取同一个次方 k，选 k 让加起来正好 1。小于 1 的数取 1 点几次方会变小，小的数变得更多，
所以也是冷门多减一点。这场 k ≈ 1.035。

三种方法的结果：

| | 主胜 | 平 | 客胜 |
|---|---|---|---|
| 按比例 | 48.28% | 27.59% | 24.14% |
| Shin 法 | 48.67% | 27.43% | 23.89% |
| 幂函数法 | 48.81% | 27.36% | 23.83% |

差别不到半个百分点，但回测几万场时会有影响。哪个更准，第 3 阶段拿真实比赛结果比较（需求文档第 16 节）。
冷门多减的原因是一个有名的现象：长期看，冷门的赔率普遍比它真实的机会给得更低（叫“热门—冷门偏差”）。

两个可以手算核对的特点：
- 没有抽水时（例如 2.0 / 4.0 / 4.0，倒数正好 0.5 + 0.25 + 0.25 = 1），三种方法都原样不变。
- 只有两个选项时（大小球、亚盘），Shin 法等于“两边减去同样多”：1.5 / 2.5 的隐含概率 66.67% + 40% = 106.67%，
  多出的 6.67% 两边各减 3.33%，得到 63.33% 和 36.67%。

交易所和“多家最高”的赔率倒数之和常常小于 1。这时 Shin 法算出的 z 是负数（“负的内幕比例”说不通），
概率照样能算出来、加起来等于 1，但用它比较方法时要知道这一点。

## 2. 亚盘和大小球怎么结算

### 盘口的写法

数据库里亚盘盘口写的是**主队让多少球，负数 = 主队让球**：-0.5 是主队让半球，+0.25 是主队受让（客队让）平半。
这是 football-data 的写法，用数据库核对过：主胜赔率低于 1.5（主队很强）的 7,758 场，97% 的盘口是负数；
例如 2021/22 曼城主场对诺维奇，盘口 -2.5。买客队时，客队的盘口就是主队的相反数（主 -0.75 = 客 +0.75）。

### 整数盘和半球盘

把“让的球”加到你买的那队的净胜球上，大于 0 赢，等于 0 走盘（退回本金），小于 0 输。
- 主队 -0.5（半球）：主队赢球就赢，平或输就输。没有走盘。
- 主队 -1：赢 2 球以上赢；刚好赢 1 球走盘；平或输就输。

### 四分之一盘：本金拆成两半

-0.25、-0.75、2.75 这类盘口，把本金拆成两半，分别下在相邻的两条线上：

| 盘口 | 中文叫法 | 拆成 |
|---|---|---|
| -0.25 | 平半 | 一半 0、一半 -0.5 |
| -0.75 | 半一 | 一半 -0.5、一半 -1 |
| 2.75 | 大小 2.75 | 一半 2.5、一半 3 |

两半各自结算，合起来五种结果：赢、赢半、走、输半、输。每下 1 元、赔率 o 的净盈亏：

| 结果 | 两半 | 净盈亏 | 赔率 1.90 时 |
|---|---|---|---|
| 赢 | 赢 + 赢 | o − 1 | +0.90 |
| 赢半 | 赢 + 走 | (o − 1) ÷ 2 | +0.45 |
| 走 | 走 + 走 | 0 | 0 |
| 输半 | 走 + 输 | −0.5 | −0.5 |
| 输 | 输 + 输 | −1 | −1 |

例 1：买主队 -0.25，赔率 1.90，下 1 元（0.5 元下 0 盘，0.5 元下 -0.5 盘）。
- 主队 1–0 赢：两半都赢，+0.45 + 0.45 = **+0.90**
- 1–1 平：0 盘那半走盘（退回 0.5），-0.5 盘那半输 0.5 → **−0.5（输半）**
- 主队输：两半都输 → **−1**

例 2：买主队 -0.75，赔率 1.90。主队刚好赢 1 球：-0.5 那半赢 +0.45，-1 那半走盘 0 → **+0.45（赢半）**。

例 3：大 2.75，赔率 2.00，全场进 3 球：大 2.5 那半赢 +0.5，大 3 那半走盘 → **+0.5（赢半）**。买小 2.75 的人同一场是输半 −0.5。

## 3. 比分矩阵

### 是什么

一张表，第 i 行第 j 列 = “主队进 i 球、客队进 j 球”的概率。所有格子加起来是 1。
所有玩法都从这一张表算出来（需求文档第 3 节），所以胜平负、亚盘、大小球之间不会互相矛盾。

手算用的小矩阵（只到 2 球，数字是编的，加起来 = 1）：

| | 客 0 | 客 1 | 客 2 |
|---|---|---|---|
| **主 0** | 0.10 | 0.08 | 0.04 |
| **主 1** | 0.15 | 0.12 | 0.03 |
| **主 2** | 0.20 | 0.17 | 0.11 |

### 从矩阵算各玩法：找出对应的格子，加起来

- **主胜**：主队进球多的格子（表的左下方）：1–0 0.15 + 2–0 0.20 + 2–1 0.17 = **0.52**
- **平**：对角线：0–0 0.10 + 1–1 0.12 + 2–2 0.11 = **0.33**
- **客胜**：右上方：0.08 + 0.04 + 0.03 = **0.15**。三个加起来 = 1。
- **大 1.5 球**：总进球 2 球以上。先算小的：0–0、1–0、0–1 = 0.10 + 0.15 + 0.08 = 0.33，所以大 1.5 = **0.67**。
- **BTTS（双方都进球）**：去掉第一行和第一列（有一队进 0 球的）：0.12 + 0.03 + 0.17 + 0.11 = **0.43**。
- **主队 -0.75**：先按净胜球分组。净胜 2 球（2–0）0.20 → 赢；净胜 1 球（1–0、2–1）0.32 → 赢半；其他 0.48 → 输。
- **正确比分**：直接看格子，例如 2–1 = 0.17。

### 亚盘的“胜算”

四分之一盘有赢半、输半，不能直接说“赢的概率”。需求文档第 3 节的折算：赢半算半个赢，输半算半个输，走盘不算：

胜算 = (赢 + 赢半 × 0.5) ÷ (赢 + 赢半 × 0.5 + 输 + 输半 × 0.5)

上面主队 -0.75：(0.20 + 0.16) ÷ (0.20 + 0.16 + 0.48) = 0.36 ÷ 0.84 = **42.9%**。公平赔率 = 1 ÷ 0.429 = 2.33。

为什么公平赔率是 1 ÷ 胜算：按赔率 o 下 1 元，期望盈亏 = (赢 + 赢半/2) × (o − 1) − (输 + 输半/2)。
令它等于 0，解出来正好是 o = 1 ÷ 胜算。程序里有自动检查：按公平赔率下注，期望盈亏一定是 0。
如果实际赔率是 2.00：期望盈亏 = 0.20 × 1 + 0.32 × 0.5 − 0.48 × 1 = **−0.12**，每下 1 元平均亏 0.12 元。

### 泊松矩阵和需求文档的例子

最简单的模型假设两队进球各自服从泊松分布、互不影响。预期进球 λ 时，进 k 球的概率 = e^(−λ) × λ^k ÷ k!。
主进 i 客进 j 的概率 = 两个概率相乘。

需求文档第 3 节的例子（主队 1.7 球、客队 1.0 球），程序算出来和文档一致：
1–0 = (e^−1.7 × 1.7) × e^−1.0 = 0.3106 × 0.3679 = 11.4%；胜平负 53.8% / 24.0% / 22.2%；
主队 -0.75 赢 29.5%、赢半 24.3%、输 46.2%，胜算 47.4%；大 2.5 球 50.6%；BTTS 51.7%。

### 表只能做到有限大：尾部怎么办

进球数理论上没有上限，表每队只算到 10 球。程序把“10 球及以上”的概率全部放进最后一行/列，所以表加起来正好是 1。
代价是把“11 球”当成“10 球”算，只影响让 9 球以上这种不会出现的盘口。预期进球 1.5 时，一队进 11 球以上的概率不到百万分之一。

如果有模型直接把 10 球以上丢掉，表加起来就不到 1（例如预期进球 4.5 对 4.0 时只有 0.989）。
程序发现加起来和 1 差超过百万分之一就报错，不会悄悄放大，因为那样每个玩法都会偏一点，又看不出来。

## 4. 评分指标：概率准不准

结果只发生一次，一场比赛没法说“60% 对不对”。要看很多场的平均分。下面三个分数都是越小越好。

例子：两场比赛。第 1 场预测 [主胜 0.5, 平 0.3, 客胜 0.2]，实际主胜；第 2 场预测 [0.2, 0.3, 0.5]，实际平。

### log loss（对数损失）：看“真实发生的结果，你给了多少概率”

每场的分数 = −ln（真实结果的预测概率）。
- 第 1 场：−ln 0.5 = 0.693；第 2 场：−ln 0.3 = 1.204；平均 **0.949**。
- 给真实结果 0.9 只扣 0.105，给 0.1 扣 2.303。给了 0 会扣到无穷大。
  所以程序把概率截到不低于 1e-15（settings.yaml 的 `calc.logloss_eps`），这时一场扣 34.5 分，很重但能算平均。
- 三个结果都猜 1/3 的“什么都不知道”模型：ln 3 = 1.099。比这个还差，说明模型帮了倒忙。

### Brier 分数：看每个结果“预测概率和实际 0/1 差多少”

每个结果 (预测 − 实际)² 加起来。实际发生的是 1，没发生的是 0。
- 第 1 场：(0.5 − 1)² + 0.3² + 0.2² = 0.25 + 0.09 + 0.04 = 0.38
- 第 2 场：0.2² + (0.3 − 1)² + 0.5² = 0.04 + 0.49 + 0.25 = 0.78；平均 **0.58**
- 只有“是/否”的玩法（BTTS）常用另一种写法，只算“是”那一项：预测 0.6、真的发生 → (0.6 − 1)² = 0.16。
  两种写法差 2 倍，比较时要用同一种。

### RPS（排序概率分数）：胜平负是有顺序的

主胜 → 平 → 客胜是有顺序的。真实是主胜时，把概率放在“平”（差一点）应该比放在“客胜”（完全反了）扣分少。
Brier 不管顺序，RPS 管。做法是先“累计”：第 1 项 = 主胜，第 2 项 = 主胜 + 平。差的平方加起来再除以 2。
- 第 1 场：累计预测 [0.5, 0.8]，累计实际 [1, 1] → ((0.5 − 1)² + (0.8 − 1)²) ÷ 2 = (0.25 + 0.04) ÷ 2 = **0.145**
- 对比：实际主胜，预测 [0.4, 0.6, 0] 和 [0.4, 0, 0.6] 的 Brier 一样都是 0.72；
  RPS 一个是 0.18（概率放在平），一个是 0.36（概率放在客胜）。

### 校准：模型说 60% 的事，是不是大约六成发生了

把所有预测按概率分箱（0–10%、10–20%……，settings.yaml 的 `calc.calibration_bins` = 10），
每个箱里比较“平均预测”和“实际发生的比例”。差距 gap = 实际 − 预测：正数说明模型低估了，负数说明高估了。
画成图就是校准曲线，完全校准时所有点落在对角线上。

**ECE** 把校准表压成一个数：每个箱的 |gap| 按场数加权平均。
例：箱 A 10 场、平均预测 25%、实际 20%；箱 B 30 场、平均预测 65%、实际 70%。ECE = (10 × 5% + 30 × 5%) ÷ 40 = **5%**。
箱分得越细、场数越少，ECE 越容易因为运气变大，所以只在同样分箱、差不多场数之间比较。

### 三个分数看的东西不一样

| 指标 | 主要看什么 | 特点 |
|---|---|---|
| log loss | 真实结果的概率给得够不够 | 对“很有把握却错了”罚得最重 |
| Brier | 每个结果的概率偏了多少 | 不会到无穷大，比较温和 |
| RPS | 胜平负的概率放的方向对不对 | 考虑顺序，足球论文常用 |
| 校准表 / ECE | 说 60% 的事是不是六成发生 | 只看“说的概率可不可信”，不看区分能力 |

校准好不等于准：每场都猜“主胜 45%”的模型校准可以很好（长期主胜确实约 45%），但它分不出强队弱队。
所以要几个指标一起看。

## 6. 练习题

**题 1**：买主队 -1.25，赔率 1.95，下 1 元。比分 2–1，盈亏多少？

**题 2**：买小 2.25，赔率 1.90，下 1 元。比分 2–0，盈亏多少？

**题 3**：胜平负赔率 1.8 / 3.6 / 4.5，按比例去水后三个概率各是多少？结果客胜时，这个去水概率的 RPS 是多少？

---

**答案 1**：-1.25 拆成 -1 和 -1.5。主队赢 1 球：-1 那半走盘（0），-1.5 那半输（−0.5）→ **输半，−0.5**。

**答案 2**：2.25 拆成 2 和 2.5。进 2 球：小 2 那半走盘（0），小 2.5 那半赢（0.5 × 0.90 = +0.45）→ **赢半，+0.45**。

**答案 3**：隐含概率 1/1.8 = 0.5556，1/3.6 = 0.2778，1/4.5 = 0.2222，合计 1.0556（抽水约 5.6%）。
各除以 1.0556 → 主胜 **52.6%**、平 **26.3%**、客胜 **21.1%**（正好是 10/19、5/19、4/19）。
客胜时累计实际 [0, 0]，累计预测 [0.526, 0.789]：RPS = (0.526² + 0.789²) ÷ 2 = (0.277 + 0.623) ÷ 2 = **0.45**。
（程序算出 0.4501。主胜热门、结果却是客胜，所以分数很高。）
