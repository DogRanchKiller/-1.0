# 第 1b 阶段：国内网站和英文首发 / 伤停来源调研

调研日期：2026-10-30（北京时间 10-31 凌晨，约 UTC 16:50–17:40）
用途：给你决定第 1b 阶段的爬虫用哪些网站。这次只看规则和可行性，没有抓数据、没有存数据文件。

## 先看结论

1. **伤停、首发、赛程开球时间：找到了合适的来源。** FotMob 的比赛页面本身就带首发、替补、伤停名单（带“最后更新时间”）、
   UTC 开球时间，还有 xG。它的 robots.txt 只禁止 `/api/`，不禁止这些页面。缺点是它的使用条款没读到（要你在浏览器看一眼）。
   英超另外有官方 Fantasy（FPL）接口，伤停带“第一次出现的时间”，可以用来核对。
2. **竞彩赔率：可以用官方来源。** 竞彩网（中国体育彩票官方）的数据接口能直接拿到当天在售比赛的胜平负、让球胜平负赔率和中文队名。
   历史赔率接口拒绝访问，所以竞彩只能从开始抓的那天起积累，不能回补。
3. **多家公司变盘记录（亚盘、大小球、欧赔）：没有一个“规则允许、技术上又不用绕过拦截”的国内网站。**
   - 球探、澳客的用户协议明文禁止用程序抓取；500 彩票网的赔率页有防机器人验证；雷速的 robots.txt 点名禁止 Claude 的爬虫；
     中国足彩网、澳门彩票被防火墙拦住。
   - 只剩 7M：robots.txt 没有限制，但使用条款写着“未经书面许可不得复制”。要你决定。
   - 这一条影响很大：不只是回补，**上线后实时预测要用的“当时的赔率”也要靠它**（第 5 节融合概率）。见第 6 节问题 1。
4. **平博（Pinnacle）收盘赔率（待定问题 7）：没找到能用的来源。** 建议走第 18 节第 7 条已经写的备选：“只用多家平均”。
5. **中文队名：**懂球帝手机版网页和竞彩接口都有中文队名（现役球队）；已经降级、很久没踢五大联赛的老球队用中文维基百科补，最后你确认。

## 调研方法

- 每个网站先读 robots.txt，再找使用条款，最后为判断可行性看 1–3 个页面。请求间隔 3–5 秒，全部约 125 次请求。
- 程序标识（User-Agent）如实写：`FootballLearningProject/0.1 (personal study; https://github.com/DogRanchKiller/-1.0)`。
- 没有登录、没有注册、没有绕过任何验证码或防火墙。遇到验证页、拦截页就停，只记录结果。
- robots.txt 禁止的路径没有访问。robots.txt 点名禁止 AI 程序的网站（雷速、ESPN、BBC）只读了 robots.txt。
- 本次网页搜索工具用不了（报错），条款都是直接打开网站找的，找不到的写“未找到”。
- 页面只在临时文件夹里看，调研结束就删了，没有存进项目。

### robots.txt 的几种结果是什么意思

| 结果 | 意思 |
|---|---|
| 允许 | 规则没有禁止我们要用的路径 |
| 禁止 AI | 规则里点名禁止 ClaudeBot、anthropic-ai、GPTBot 等 AI 程序。按 CLAUDE.md 要你决定 |
| 禁止相关路径 | 一般程序可以访问网站，但放数据的路径被禁止 |
| 全部禁止 | 所有程序都不能访问 |
| 读不到（5xx） | 服务器出错。按 robots.txt 的标准（RFC 9309），读不到时应当当作“全部禁止” |
| 没有（404） | 网站没写规则，等于不限制；但使用条款照样要遵守 |

- 常见写法：`Disallow: /*?*` 表示“网址里带问号的都不许访问”；`Disallow: /fenxi1/` 表示这个文件夹下都不许访问。

## 1. 总表

“技术难度”指不绕过任何拦截的前提下写爬虫难不难：低 = 数据就在网页或接口里；中 = 要多找一层数据文件；高 = 被验证页 / 防火墙挡住，不绕过就拿不到。

## 2. 国内网站逐个说明

### 2.1 球探（www.titan007.com，现名“新球体育”）

robots.txt（主站 www，原文）：
```
User-agent: *
Disallow: /bin/
...
Disallow: /*?*
```
- 比分站 live.titan007.com 也是 `Disallow: /*?*`，另外禁止 `/vbsxml/`、`/detail/`。比分页的数据正是从 `/vbsxml/` 加载的。
- 赔率子站 1x2.titan007.com 的 robots.txt 返回“500 内部服务器错误”；vip.titan007.com、zq.titan007.com 连不上，www.win007.com 返回 502。
  按 robots.txt 标准，读不到当作全部禁止。所以这些子站都没有访问。

使用条款：《新球体育用户服务协议》，https://www.titan007.com/about/about.html#userRule
- 第 6.2 条原文：“未经本平台事先书面同意，用户不得擅自通过包括但不限于任何机器人、‘蜘蛛’等程序或设备监视、复制、传播、展示、镜像、上载、下载本平台及相关服务中的内容。”
- 第 5.1 条：数据“只供您自己合法参考”，不得复制、出售或用于商业目的。
- 页脚有“数据服务”链接，指向 feijing88.com（他们卖数据的业务）。价格和条件没看。

结论：条款明文禁止用程序下载，不用。如果以后想要它的变盘数据，正规做法是联系他们的数据服务（付费，未核实价格）。

### 2.2 500 彩票网（500.com）

robots.txt 关键部分（odds.500.com，赔率站，原文节选）：

- trade.500.com（竞彩投注页）禁止 `/jczq/?`（带参数的竞彩页）和 `/static/public/jczq/xml/hisdata/`（竞彩历史数据）。
- liansai.500.com（联赛资料）禁止 `/season_`、`/seasonindex*`、`/team_*.php?`。live.500.com（比分）禁止 `/detail.php?fid=*`。
- 没有点名禁止 AI 程序。

使用条款：https://www.500.com/about/copyright.shtml
- “本网站提供的任何内容（包括但不限于数据……）的版权均属于 500.com 或相关权利人。未经 500.com 或相关权利人事先的书面许可，
  您不得以任何方式擅自复制、再造、传播、出版、转帖、改编或陈列本网站的内容。”

观察：
- 竞彩投注页 https://trade.500.com/jczq/ （不带参数，robots 允许）的网页里直接写着每场的赔率、中文队名、北京时间开球时间，
  例如 `data-homesxname="科特布斯" data-awaysxname="波鸿" data-matchdate="2026-10-31" data-matchtime="01:30" data-rangqiu="1"`。
- 单场亚盘页 `odds.500.com/fenxi/yazhi-1430744.shtml`（robots 允许）返回的不是内容，而是一段防机器人脚本
  （要浏览器算出一个叫 `EO_Bot_Ssid` 的 cookie 才放行）。按规则没有绕过。欧赔页、2009 年左右的老比赛页也一样。
- 历史变盘数据放在 `/fenxi1/`，robots 禁止。

结论：赔率和变盘拿不到（验证页 + robots 禁止），不用。竞彩投注页可以当竞彩网的备用，但它的条款不许复制，建议只在竞彩网坏了时再考虑。

### 2.4 竞彩网（www.sporttery.cn，中国体育彩票官方信息平台）

robots.txt（www.sporttery.cn，原文全文）：
```
User-agent: *
Disallow: /*.pdf$
Disallow: /*.js$
Disallow: /*.json$
Disallow: /*.php$
Disallow: /*.mp4$
```
- 页面里的赔率由数据接口 webapi.sporttery.cn 提供。这个子站没有 robots.txt（返回 404），所以不受限制。
  接口网址以 `.qry` 结尾，也不在主站禁止的类型里。
- 体彩中心的 www.lottery.gov.cn 规则一样（禁止 pdf、js、json、php、mp4）。

使用条款：未找到（页脚由程序加载，静态网页里没有条款链接）。

观察：
- 接口 `https://webapi.sporttery.cn/gateway/jc/football/getMatchCalculatorV1.qry?poolCode=hhad,had&channel=c` 直接返回 JSON（表格式数据），
  有每场的联赛中文名、主客队中文名和英文缩写、北京时间开球时间、胜平负（had）和让球胜平负（hhad，含让几球）的赔率，
  每种赔率都带“更新时间”。例如：德乙 科特布斯 vs 波鸿，2026-10-31 01:30，胜平负 3.12 / 3.60 / 1.85，让球 +1。
- 赛果和历史接口（`getMatchResultV1.qry`）、单场赔率变化接口（`getFixedBonusV1.qry`）都返回“禁止访问”（403）。
  一分钟后再查当天接口仍然正常，说明不是封了 IP，而是这两个接口不对外。没有尝试伪装来源去绕过。
- 开球时间是北京时间（周五 18:30 的德乙在这里写 10-31 01:30，对得上）。入库时要换成 UTC。

结论：用。竞彩赔率的主来源，每天抓几次当天在售比赛，自己积累变化。历史竞彩赔率不能回补。
竞彩只开一部分比赛（五大联赛多数场次有，具体覆盖多少要抓一段时间再统计）。

### 2.5 懂球帝（www.dongqiudi.com / m.dongqiudi.com）

robots.txt：
- 电脑版 www.dongqiudi.com/robots.txt 对我们返回“403 Forbidden”（首页却能正常打开）。按标准，4xx 等于没有限制，但不清楚这是不是有意拦程序。
- 手机版 m.dongqiudi.com（原文）：
  ```
  User-agent: *
  Allow: /
  Disallow: /_s/
  ```
- 接口子站 api.dongqiudi.com（原文）：`User-agent: *` `Disallow:`（空，等于全部允许）。

使用条款：未找到网页版。网页上的“协议”链接跳到 App 下载页。

观察：
- 手机版赛程页 https://m.dongqiudi.com/match 是服务器直接生成的网页，赛程数据在网页里，包括中文队名、懂球帝自己的球队编号、比分、状态。
  注意它的字段名有误导：`date_utc` / `time_utc` 实际是北京时间，`start_play` 才是 UTC（同一场：time_utc 01:00，start_play 前一天 17:00）。
- 单场页（例如 `/matchDetail/54594240/live`）有比分、技术统计、进球和换人事件（球员中文名）。“阵容”页的首发名单不在网页里，由程序另外加载。

结论：待你决定。适合给中文队名（现役球队）和核对赛程；首发、伤停不靠它。
