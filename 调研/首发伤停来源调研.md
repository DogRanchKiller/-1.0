# 首发、伤停来源调研（工作树丙）

调研日期：2026-10-31（北京时间 06:00–07:30 左右，UTC 10-30 22:00–23:30）
用途：给你决定首发、伤停、球员出场时间用哪些来源。只调研，没写采集程序，没往项目里存数据文件。

## 先看结论

1. **历史首发和出场时间：找到了，而且规则清楚。** GitHub 上的开源数据集 transfermarkt-datasets（CC0 公有领域，随便用）
   有五大联赛 2012/13–2025/26 每场的出场名单和出场分钟数，2013/14 起有完整首发 11 人（含位置、号码）。
   原来指望的 Understat 不能用，这个可以替代，覆盖年份还更长。
   缺点：数据集 2026-07 起停更，**2026/27 赛季（现在这个赛季）没有**。
2. **历史伤病：找到一个，但许可不清楚。** 另一个 GitHub 数据集（salimt/football-datasets）有 16.8 万条伤病记录
   （开始日期、结束日期、缺阵天数、缺阵场数），2015 年起每年几千条，球员编号和上面的数据集是同一套。
   **它没有写许可证**，按惯例等于“保留所有权利”，只适合本机个人学习、不转发。要你决定（问题 2）。
   这和第 13 节“历史伤停多半拿不到”的判断不一样，伤停特征有可能不用等几百场积累。
3. **实时首发和伤停（赛前就能拿到）：没有新的免费来源。** 这次查的里面，免费又覆盖五大联赛的都不行
   （规则禁止、只有英超、或者数据不全）。剩下的选择：
   - FotMob 比赛页：你说过 FotMob 不用（`/api/` 被禁止），但之前第 1b 阶段的调研（工作树 F，`调研/第1b阶段_国内网站来源调研.md` 3.1 节）
     发现比赛页本身的网页里就有首发、伤停，robots.txt 允许比赛页，只是条款没读到。这个分歧还没定（问题 1）。
     这次按你的要求没有访问 FotMob。
   - 付费接口：Sportmonks €29/月起（robots.txt 明确欢迎 AI 程序）；api-football（robots.txt 欢迎 AI，但官网被 Cloudflare 挡住，价格没看到）。
   - 英超可以免费：官方 Fantasy（FPL）接口有每个球员的伤停状态、出场概率、消息出现时间。
   - 懂球帝：待主项目核实（这次没访问）。
4. **球员名：建议改成以 Transfermarkt 的球员编号为准**（不再是 Understat）。首发、出场分钟、伤病三张历史表都用这套编号，
   不用对名字。实时来源要和它对名字：FPL 的全名和 Transfermarkt 的名字直接完全一样的只有 57%
   （FPL 用全名，例如 “David Raya Martín”，Transfermarkt 用常用名 “David Raya”），要做自动匹配 + 抽查。

## 调研方法

- 每个网站先读 robots.txt，再找条款，再看 1–3 个样例页面。请求间隔 3–7 秒，全部约 80 次请求。
- 程序标识如实写：`FootballLearningProject/0.1 (personal study; https://github.com/DogRanchKiller/-1.0)`。
- 没有登录、注册，没有绕过验证页。robots.txt 点名禁止 Claude 的网站只读了 robots.txt。
- 开源数据集为了核对覆盖年份，把 4 个表下载到电脑的临时文件夹统计（games 5MB、game_lineups 126MB、
  appearances 45MB 下载两次、伤病表 9MB），统计完就删了，没进项目文件夹。
- 网页搜索工具这次用不了（报错），条款、价格都是直接打开网站看的。
- 已经查过、不能用的没有重查：Understat、FBref、Sofascore、WhoScored、FotMob、theanalyst.com、footballxg.com；football-data 没有首发。

## 首发什么时候公布

- 这次调研时（北京时间早上 7 点）没有正在进行的比赛，没法实测“开球前多久能拿到首发”。
- 一般做法是各队在开球前约 1 小时交名单、同时公布【未核实，各联赛规则没查到原文】。第 2 节已经按“开球前 60 分钟起反复检查，
  30 分钟前还没有就不等”设计，不用改。
- 建议：实时首发开抓后，每场记“第一次看到首发的时间”，攒一个月就知道各联赛实际提前多久，比查规则更准。
- 历史首发只能用于 T-1 版的回测（T-24、T-6 时首发还没公布）。

## 几个要注意的地方

- **伤病表的“结束日期”“缺阵天数”“缺阵场数”是事后才知道的**，回测时不能用（第 16 节“不偷看未来”）。
  赛前能用的只有“这名球员在这天之前开始受伤、还没确认复出”，而且“开始日期”是事后整理的，消息真正公开的时间可能晚一两天。
  用之前要先查：同一名球员伤病结束后多快重新出场，和出场表对一下。
- **停赛不在伤病表里**，要从出场表、事件表的红黄牌自己推（各联赛累计黄牌停赛规则不同）。
- **2026/27 的缺口**：Transfermarkt 数据集没有本赛季。英超可以用 vaastav 的 FPL 数据补出场分钟；
  其他四个联赛本赛季已经踢过的比赛，只有等实时来源开抓后的比赛才有，或者等数据集恢复更新。
- **出场分钟最多 90**：算“球员出场时间”够用，算“补时阶段在场”不够（项目里目前没这个需要）。
